Итерация 2:
1. Депозит денег пользователем
2. Перевод денег с одного аккаунта на другой
3. Изменение имени пользователя

Требования:
1) Имя профиля - два слова сотсоящие только из букв обязательно
2) Максимальная сумма депозита 5000
3) Максимальная сумма перевода 10000

1.1 Депозит денег пользователем
Позитивный кейс
1. Пополнение счёта на сумму в диапозоне 0.01 - 5000.00
- Авторизоваться Админом -> Создать нового пользователя -> Авторизоваться созданным пользователем
  -> Создать аккаунт (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать кнопку "Deposit Money"
- В поле "Select Account" выбрать созданный аккаунт
- Заполнить поле "Enter Amount" валидным значением
- Нажать кнопку "Deposit"
Ожидаемы результат:
- Отображается сообщение "✅ Successfully deposited $<СУММА ПОПОЛНЕНИЯ ИЗ ШАГА ВЫШЕ> to account ACC1!"
- Средства поступили на счёт (проверить через API)

Негативный кейс
1.Проверка отображения ошибки при поптке пополнить баланс счёта без выбора аккаунта
- Авторизоваться Админом -> Создать нового пользователя -> Авторизоваться созданным пользователем
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать кнопку "Deposit Money"
- Поле "Select Account" оставить пустым
- Заполнить поле "Enter Amount" валидным значением
- Нажать кнопку "Deposit"
Ожидаемы результат:
- Отображается сообщение "❌ Please select an account."

2.Проверка отображения ошибки при поптке пополнить баланс счёта на невалидную сумму
- Авторизоваться Админом -> Создать нового пользователя -> Авторизоваться созданным пользователем
   -> Создать аккаунт (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать кнопку "Deposit Money"
- В поле "Select Account" выбрать созданный аккаунт
- Заполнить поле "Enter Amount" невалидным значением (например 5500)
- Нажать кнопку "Deposit"
Ожидаемы результат:
- Отображается сообщение "❌ Please deposit less or equal to 5000$."
- на счет средства не поступили (проверить через API)

2.2 Перевод денег с одного аккаунта на другой
Позитивный кейс
1. Перевод денег между счётами пользователя
- Авторизоваться Админом -> Создать нового пользователя -> Авторизоваться созданным пользователем
  -> Создать аккаунт -> Пополнить счёт созданного аккаута -> Создать ещё один аккаунт (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать кнопку "Make a Transfer"
- В поле "Select Your Account" выбрать счёт па который был совршён депозит
- Поле "Recipient Name" заполнить именем текущего пользователя
- В поле "Recipient Account Number" ввести название второго созданного аккаунта
- Заполнить поле "Amount" валидной суммой
- Активировать чек-бокс "Confirm details are correct"
- Нажать кнопку "Send Transfer"
Ожидаемы результат:
- Отображается сообщение "✅ Successfully transferred $<СУММА ПЕРЕВОДА ИЗ ШАГА ВЫШЕ> to account <НАИМЕНОВАНИЕ АККАУНТА>!"
- Баланс аккаунтов изменился на сумму перевода (проверить через API)

Негативный кейс
1. Проверка отображения ошибки при попытке перевода без выбора счёта-отправителя
- Авторизоваться Админом -> Создать нового пользователя -> Авторизоваться созданным пользователем
  -> Создать аккаунт -> Пополнить счёт созданного аккаута -> Создать ещё один аккаунт (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать кнопку "Make a Transfer"
- Поле "Select Your Account" оставить пустым
- Поле "Recipient Name" заполнить именем текущего пользователя
- В поле "Recipient Account Number" ввести номер аккаунта пользователя
- Заполнить поле "Amount" валидным значением
- Активировать чек-бокс "Confirm details are correct"
- Нажать кнопку "Send Transfer"
Ожидаемый результат:
- Отображается сообщение "❌ Please fill all fields and confirm."
- Баланс введенного аккаунта не изменился (проверить через API)

3.3 Изменение имени пользователя
Позитивный кейс
1.Проверка изменения имени пользователя
- Авторизоваться Админом -> Создать нового пользователя (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать на имя пользвателя
- Заполнить поле ввода волидным занчением (например "Kate Smith")
- Нажать кнопку "Save Changes"
Ожидаетмый результат:
- Отображается сообщение "✅ Name updated successfully!"
- На сайте имя пользователя изменилось на введенное значение
- Имя пользователя сменилось на введенное значение (проверить через API)

Негативный кейс
1.Проверка отображения ошибки при попытке сменить имя пользвателя на невалидное значение
- Авторизоваться Админом -> Создать нового пользователя (через API)
- Перейти на страницу http://localhost:3000/dashboard под созданным пользователем
- Нажать на имя пользвателя
- Заполнить поле ввода волидным занчением (например "Kate Smith1")
- Нажать кнопку "Save Changes"
Ожидаетмый результат:
- Отображается сообщение "Name must contain two words with letters only"
- На сайте имя пользователя не изменилось
- Имя пользователя не изменилось на введенное значение (проверить через API)
